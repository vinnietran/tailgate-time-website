# TailgateTime Host Acquisition Playbook

## Goal

Get the first repeatable group of hosts using TailgateTime for real game-day events.

The short-term target is not downloads. The target is:

- 25 qualified host conversations
- 10 hosts onboarded
- 5 published tailgates
- 3 hosts who invite guests through TailgateTime
- 1 repeatable acquisition channel proven by replies and events created

An active host means someone who creates or publishes an event, shares it with guests, and uses at least one game-day workflow: RSVPs, paid spots, messages, check-in, or discovery.

## Core Strategy

Start narrow. Win one host segment before trying to win the whole tailgating market.

Best first segment:

**Existing organizers who already run tailgates through group texts, DMs, Venmo, spreadsheets, and manual guest lists.**

They already have the problem. They already have guests. They do not need to be convinced to tailgate. They need a better operating system for the tailgate they already run.

Avoid starting with generic fans. Generic fans may like the idea, but hosts create supply. Supply creates events. Events create proof.

## Positioning

### One-Line Pitch

TailgateTime helps tailgate hosts manage invites, RSVPs, paid spots, guest updates, and check-in without juggling group texts, DMs, spreadsheets, and payment apps.

### Short Host Pitch

You already do the hard part: bringing people together on game day. TailgateTime gives you one place to organize the event, share the link, track who is coming, message guests, and manage free or paid access.

### Pain-First Pitch

Most tailgate hosts are running game day through scattered texts, DMs, Venmo requests, screenshots, and memory. TailgateTime turns that into one event page with RSVPs, messaging, check-in, and host tools.

### What Not To Lead With

Do not lead with “download our app.” Lead with:

- “I can set up your next tailgate for you.”
- “You can send one link instead of chasing people.”
- “You can know who is coming before game day.”
- “You can run paid or free tailgates without messy tracking.”

## The Offer

Create a founding host offer that removes friction.

### Founding Host Offer

For your first TailgateTime event, we will:

- Set up the event page for you
- Help choose the right format: private invite, open free, or open paid
- Give you invite copy to send guests
- Feature your tailgate where appropriate
- Help you use check-in or guest messaging on game day
- Collect feedback after the event

Optional incentives:

- Founding Host badge
- Featured host spotlight
- First-event fee waiver if applicable
- Referral reward for introducing another host
- Free printed QR flyer template

Keep incentives simple. The real value is white-glove setup.

Score each lead from 1 to 5.

5: Already hosts paid/public tailgates or recurring alumni/fan events

3: Runs a fan group or has clear tailgate activity  
2: General fan account with occasional tailgate posts  
1: No clear hosting behavior

Focus outreach on 4s and 5s first.

## Outreach Rules

Do not spam groups. Do not drop links first. Ask for a conversation or offer help.

Rules:

- Personalize the first line.
- Mention the specific hosting behavior you noticed.
- Keep the first message short.
- Ask for a low-friction yes/no response.
- Do not send app links until they show interest.
- Follow up twice, then stop.

## Discovery Call Script

Keep this to 15 minutes.

### Questions

1. How do you currently invite people?
2. How do you track who is coming?
3. Do you charge, collect contributions, or keep it free?
4. How many people usually attend?
5. What is the most annoying part of organizing it?
6. Do you need public discovery, private invites, or both?
7. Would you be comfortable trying TailgateTime for one event if we set it up for you?

### What To Listen For

Strong buying signals:

- “I never know how many people are coming.”
- “People pay me late.”
- “I use a spreadsheet.”
- “I send a million texts.”
- “We host every home game.”
- “We want more people to find us.”
- “Check-in is messy.”

Weak signals:

- “Sounds cool.”
- “Maybe someday.”
- “I only go to other people’s tailgates.”

Prioritize pain, not politeness.

## Concierge Onboarding Flow

Do not make early hosts figure it out alone.

### Step 1: Collect Details

Ask for:

- Tailgate name
- Date and time
- General location
- Private, open free, or open paid
- Capacity
- Host name
- Description
- Any guest instructions
- Hero image or logo if they have one
- Whether they want RSVPs, tickets, messaging, or check-in

### Step 2: Build The Event For Them

Create the first event or walk them through it live.

### Step 3: Give Them Invite Copy

Private invite:

I’m using TailgateTime for our next tailgate so we can keep RSVPs and updates in one place. RSVP here: [link]

Open free:

We’re hosting an open game-day tailgate. RSVP through TailgateTime so we know who’s coming and can send updates: [link]

Open paid:

Spots for our game-day tailgate are live on TailgateTime. Grab your spot and check event details here: [link]

### Step 4: Pre-Game Follow-Up

Two days before event:

Hey [Name], your TailgateTime event is ready. Before you send it out, do you want me to review the description, capacity, or guest instructions?

Morning of event:

Hope game day goes smoothly. If you use check-in or messaging today, send me any friction you hit and I’ll help clean it up.

### Step 5: Post-Event Feedback

Ask:

- How many people came?
- Did TailgateTime save time anywhere?
- What felt confusing?
- Would you use it again?
- Can we feature your event as a host spotlight?
- Who is one other host I should talk to?

## 30-Day Metrics

Track these every day:

- Leads added
- Messages sent
- Replies
- Positive replies
- Calls booked
- Calls completed
- Hosts onboarded
- Events created
- Events published
- Event links shared
- RSVPs or tickets generated
- Repeat host commitments
- Referrals received

Healthy early benchmarks:

- Reply rate: 10% to 25%
- Call booking rate from replies: 25% to 50%
- Event creation rate from calls: 30% to 60%
- Repeat interest from active hosts: 30%+

If reply rate is low, improve targeting and first message.

If calls happen but events do not get created, improve the offer and onboarding.

If events get created but not shared, help hosts send the first invite.

## Objection Handling

### “I already use Facebook Events.”

Totally makes sense. TailgateTime is not trying to replace every social channel. The difference is that it gives the host purpose-built tools for tailgates: event type, guest tracking, messaging, paid/free options, and check-in. You can still promote wherever your group already lives.

### “My group just uses texts.”

That works until the group gets big or plans change. TailgateTime gives you one place to keep the details current and track who is coming.

### “I do not want to make people download another app.”

Fair. For the first event, the goal is just to give guests one clear place to RSVP and get updates. We can keep the setup simple.

### “We do not charge.”

That is fine. TailgateTime supports open free and private invite events too.

### “I do not have time to set it up.”

That is exactly why we are helping early hosts. Send the basics and we can set up the first event with you.

### “I am not sure people will use it.”

Let’s test it with one event. If it does not make RSVPs or updates easier, you do not need to keep using it.
